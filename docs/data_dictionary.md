# Data Dictionary

This file describes all columns in the raw sales dataset (`Retail_Sales_Data.xlsx`).

| Column Name       | Type    | Description                          | Example      |
|------------------|---------|--------------------------------------|-------------|
| Customer Name     | Text    | Name of the customer                  | John Smith  |
| Product Category  | Text    | Category of the product sold          | Smartphone  |
| Product Name      | Text    | Specific product sold                 | iPhone 14   |
| Order Date        | Date    | Date the order was placed             | 2025-10-01  |
| Delivered Date    | Date    | Date the order was delivered          | 2025-10-05  |
| Quantity          | Number  | Number of units sold                  | 3           |
| Unit Price        | Number  | Price per unit                        | 250         |
| Payment Method    | Text    | Payment method used                   | Credit Card |
| Country           | Text    | Country of the customer               | USA         |
| Total Revenue     | Number  | Total revenue for the order           | 750         |
| Total Cost        | Number  | Total cost for the order              | 500         |
| Net Profit        | Number  | Revenue minus cost                    | 250         |
| Status            | Text    | Order status                          | Delivered   |
